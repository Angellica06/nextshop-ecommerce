# 🛒 NextShop

Projeto de e-commerce desenvolvido com Next.js, React e Tailwind CSS, com foco em prática e evolução no desenvolvimento front-end.

## 🛠 Tecnologias
- Next.js
- React
- Tailwind CSS


## 📌 Funcionalidades
- Manipulação de estados no React
- Paginação manual de dados
- Consumo de API com custom hook
- Melhoria de UX com scroll automático


## 📦 Como rodar o projeto
```bash
# Instalar dependências
npm install

# Rodar o projeto
npm run dev

```

## 🌐 Deploy
Acesse a aplicação online: 👉 https://nextshop-ecommerce.netlify.app
